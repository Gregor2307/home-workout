# Домашние тренировки

Простая мобильная веб-страница с тренировками А и Б, описаниями техники, ссылками на поиск видеодемонстраций, отметками подходов и таймером отдыха.

## Запуск
Откройте `index.html` в браузере. Для размещения онлайн загрузите `index.html`, `style.css`, `script.js` в корень репозитория GitHub, затем включите **Settings → Pages → Deploy from a branch → main / (root)**. Дождитесь публикации адреса страницы.

На Android в Chrome откройте опубликованный адрес → меню ⋮ → «Добавить на главный экран».

## Обновлённая программа

- В каждой тренировке 6 упражнений, 3 суперсета по 2 упражнения и 3 рабочих подхода на упражнение — всего 18.
- После выбора А/Б откроется подготовка с оборудованием и рабочими весами. Нажмите «Начать тренировку»; при наличии сохранённого занятия — «Продолжить тренировку».
- В А используются одна гантель 10,5 кг, затем две по 4,5 кг и устойчивый низкий стол. Соединительный гриф не нужен; три гантели одновременно не требуются.
- В Б используются штанга 20,5 кг, две гантели по 7,5 кг, эспандер Original FitTools FT-EX-208-13 (5–15 кг) и штанга 8,5 кг для бицепса. Для двух упражнений со штангой используется один соединительный гриф с изменением веса. Вес штанги включает гриф и блины.
- Приседания, ягодичный мостик и подъёмы на носки выполняются без дополнительного веса.
- Во время занятия список доступен в секции «Оборудование и рабочие веса». В каждом суперсете чередуйте упражнения, отдыхая 90 секунд между кругами; таймер запускается вручную, как раньше.

Конфигурация программы находится в объекте `workouts` в `script.js`. Из неё формируются подготовка, карточки, количество подходов и общий прогресс. Техника и видеопоиск хранятся отдельно в `exercises`.

## Совместимость сохранений

Ключи `homeworkout-progress-A`, `homeworkout-progress-B` и `homeworkout-history` сохранены. Старые записи истории без указания количества подходов отображаются как занятия с двумя подходами (12 всего). Новые записи содержат `sets`, `total`, `version` и снимок отметок `progress`.

В старом незавершённом занятии отметки остаются на месте, третий подход не отмечается автоматически. После продолжения занятие использует актуальную программу с 18 подходами. Дополнительные ключи `homeworkout-session-A/B` и `homeworkout-last-day` позволяют предложить продолжение, в том числе если занятие начато, но ещё нет отметок.

История при обновлении не очищается и больше не обрезается до 30 записей. На главном экране по-прежнему показываются последние 6. Если историю невозможно прочитать, завершение занятия не перезаписывает её и сохраняет текущие отметки.

## Проверки без браузера

При установленном Node.js доступны необязательные проверки для разработки (приложению Node.js не требуется):

```text
node --check script.js
node --test tests/logic.test.cjs
git diff --check
```

Семь тестов используют подмену DOM и localStorage в памяти: проверяют программу и веса, подготовку, завершение А/Б на 18 подходах, восстановление старых отметок, сохранение всей старой истории, переключение/сброс и команды таймера. Браузер они не запускают; реальную вёрстку, течение времени и поведение на OnePlus эти тесты не проверяют.

Для публикации достаточно обновить `index.html`, `style.css` и `script.js` в существующей ветке GitHub Pages. Новые зависимости, сборка и изменение настроек Pages не нужны. Публиковать нужно по тому же адресу: localStorage привязан к адресу сайта и браузеру.

## Важно
- Отметки и история хранятся локально в браузере (localStorage). При очистке данных сайта они пропадут.
- Ссылки на YouTube открывают **поиск видео**, а не проверенный конкретный ролик.
- В первой версии нет встроенных фото: приоритет отдан быстрому запуску и подробным текстовым инструкциям. Фото можно добавить позднее.
- Для видео требуется интернет; страница без PWA-кеширования также требует соединения при открытии с GitHub Pages.
